01 / PLAY三步開始追月

01 — 瞄準

按住畫面，拖曳方向

按「開始追月」進入關卡。拖曳手指調整瞄準線，試下瞄準月亮前方，預判佢嘅移動。

02 — 射箭

睇準時機，放手發射

放開手指就會射箭。限時內命中五次即勝出；時間用完亦可以重新挑戰。

03 — 再挑戰

逐關加速，練好準繩度

月亮會隨關卡移動得更快，第 12 關起速度封頂。右上角可暫停，切換 App 亦會自動暫停。

02 / REWARD儲起每一次團圓

月

勝利獎勵：蓮蓉月餅 × 1

月餅總數及下一關進度會自動儲存在裝置，關閉再開仍然保留。主頁按「月餅收藏」即可查看。月餅屬遊戲內虛擬收藏。

03 / BUILD用 Android Studio 開啟

  1. 下載或 clone 專案。在 Android Studio 選擇 Open，開啟包含 settings.gradle.kts 嘅專案根目錄。
  2. 完成 Gradle Sync。依提示安裝 Android SDK Platform 35 及所需 Build Tools，讓 IDE 配置 Gradle JDK；首次同步需要網絡下載依賴。
  3. 選擇裝置，再按 Run ▶。使用 Android 6.0（API 23）或以上實機或模擬器。

亦可在專案根目錄用命令列產生 debug APK：

# Windows
gradlew.bat assembleDebug
# macOS / Linux
sh gradlew assembleDebug

輸出位置：app/build/outputs/apk/debug/app-debug.apk
